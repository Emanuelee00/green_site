## OBIETTIVO
Applicazione per routing "fresco" a Marsiglia: percorsi pedonali/ciclabili che
minimizzano l'esposizione al calore urbano (UHI) usando dati satellitari Sentinel-2.

1. heatmap-marseille/ — DATI
================================================================================

File usati dal motore:
- marseille_uhi.tif              → raster UHI composito (Sentinel-2 Aug 2023)
- quartiers/quartiers.geojson    → confini 111 quartieri Marsiglia
- temp-analysis/MODIS_marseille_2000_2024.csv → LST storica 2000-2024
- indices/ndvi.tif               → NDVI Sentinel-2 (22 Aug 2023, tile 31TFH)
- indices/ndwi.tif               → NDWI Sentinel-2
- indices/swir.tif               → SWIR normalizzato (B11)
- indices/urban.tif              → Proxy impermeabilizzazione (B11/B08)

Indice UHI composito: 40% SWIR + 30% NDVI + 10% Urban + 10% NDWI
Raster CRS: EPSG:4326 — bounds: W5.25, E5.53, S43.20, N43.42 — shape 2284x2090

Indici Sentinel-2 scaricati con scripts/download_s2_indices.py da:
  AWS COG public — tile S2B_31TFH_20230822_0_L2A
  Bande: B03(Green) B04(Red) B08(NIR 10m) B11(SWIR 20m ricampionato a 10m)

Zone MODIS (9): centre_ville, nord_urbain, sud_urbain, periurbain_est,
periurbain_nord, rural_est, rural_nord, rural_ouest, rural_sud
CSV columns: LST_jour_C, LST_nuit_C, amplitude_C, annee, date, zone — Nodata: -9999

2. marseille-engine/ — BACKEND API
================================================================================

Stack: Python 3.13, FastAPI, uv — Port: 8000
Package manager: uv — SEMPRE: UV_PYTHON=/usr/bin/python3

--- Avvio ---
make run             → solo API
make start           → API + marseille-app (5173)
make start-dashboard → API + marseille-dashboard (5174)
make start-mobile    → API + fresh-route Expo (8081)

--- Routers ---
api/routers/
├── uhi.py       → /uhi/quartiers, /uhi/quartier/{nome}, /uhi/point
├── history.py   → /history/zones, /history/{zona}
├── route.py     → /route/ (A* green routing)
├── risk.py      → /risk/?month=
├── raster.py    → /uhi/raster.png, /uhi/raster/raw, /uhi/raster/bounds,
│                   /uhi/raster/all-zones-history
├── timeline.py  → /timeline/snapshot?year=, /timeline/range
└── indices.py   → /indices/{name}/raw, /indices/available
                   (name: ndvi | ndwi | swir | urban)
                   Stesso wire-format di /uhi/raster/raw (float32 + X-Raster-* headers)

--- Script utilità ---
scripts/download_s2_indices.py → scarica bande S2 da AWS COG, calcola 4 indici
  Uso: UV_PYTHON=/usr/bin/python3 uv run python scripts/download_s2_indices.py
  Gia eseguito — indici in heatmap-marseille/indices/

--- Routing ---
A* (nx.astar_path) con euristica geografica euclidea in CRS proiettato
green_weight: lunghezza base + sconto 35% pedonale + sconto 30% fresco + penalita 40% caldo

--- Boot ---
1. Carica marseille_uhi.tif in RAM (NaN=nodata)
2. Carica quartiers.geojson + zonal_stats -> 111 quartieri con uhi_mean/score/rank
3. Carica MODIS CSV
4. Scarica grafo OSM Marsiglia 3.3km (cached) + applica green_weight

--- Vincoli macchina (42 school) ---
- /home/eielmini PIENO → tutto su /goinfre/eielmini/
- Python: /usr/bin/python3 (3.13.13) — Node: v22.22.0
- npm cache: npm_config_cache=/goinfre/eielmini/.npm-cache
- npx non funziona → usare node node_modules/...

4. marseille-dashboard/ — ADMIN DASHBOARD PROFESSIONALE
================================================================================

Stack: React 19, Vite 8, TypeScript 6, Tailwind CSS 4, Recharts, Leaflet
Port: 5174 — Proxy: /api/* → localhost:8000

Design system dark professionale — NO glass-morphism, colore solo per dati
Token (C in Dashboard.tsx): base #060d14, panel #0a1520, raised #0f1f30,
border #18304a, text #d4e0ec, muted #4a6a88, hot #e05252, warm #d4914a, cool #4daa74

--- src/ ---
api/engine.ts          → fetchQuartiers, fetchRisk, fetchHistory, fetchAllZonesHistory
types/index.ts         → tipi condivisi + ZONES + AllZonesHistory
pages/Dashboard.tsx    → pagina principale unica

components/map/
  UHIMap.tsx           → Leaflet + Canvas2D overlay + layer switching per indice
  WebGLRasterLayer.ts  → Canvas2D raster (NO WebGL), cache per indice, colormaps
  TimelineSlider.tsx   → slider 2000-2024 + fonte dati anno + anomalia media citta

components/charts/
  HistoryChart.tsx     → trend LST + regressione + 2003 highlight
  SeasonalChart.tsx    → profilo stagionale (barre colorate)
  RankingChart.tsx     → 111 quartieri ordinati
  DistributionPanel.tsx → istogramma distribuzione + confronto arrondissement
  AnomalyMatrix.tsx    → griglia 9zone x 25anni (colormap divergente blu-bianco-rosso)
                          zone senza dati mostrano pattern tratteggiato + badge N/D
  MultiZoneChart.tsx   → confronto LST fino a 4 zone, pill interattive, recharts

public/
  marseille_overview.png  → immagine 2x2 indici Sentinel-2 (statica R/ggplot2)
  marseille_uhi.png       → overview UHI

--- Renderer raster ---
Canvas2D puro (no WebGL, no OES_texture_float) — universalmente compatibile
Flow: fetch float32 -> normalizza in JS -> putImageData -> L.imageOverlay
Cache per indice: primo fetch poi switch istantaneo

--- Layer indici mappa ---
Toolbar segmentata: UHI | NDVI | NDWI | SWIR | Urban
Colormaps:
  UHI:   verde->giallo->arancio->rosso
  NDVI:  rosso-bruno->giallo->verde
  NDWI:  marrone->bianco->blu
  SWIR:  verde scuro->giallo chiaro
  Urban: verde->arancio->rosso
Se TIF non disponibile -> overlay "Index not available / run download script"
Year-shift MODIS applicato solo al layer UHI (altri indici sono statici Aug 2023)

--- Features ---
Header: wordmark tipografico, Export CSV, Export GeoJSON, dot Live
KPI 5 card: avg UHI, hot/cool districts, hottest/coolest zone (top-border colorato)
Mappa: Pixel/Districts/Both + UHI Score/Heat Risk + indice selector + timeline
Districts: threshold filter slider (0-90%), lista filtrata con stats
Quartier detail: score gauge, percentile, monthly risk bars, distribution panel
Analysis Tools:
  - Zone x Year Anomaly Matrix (hover per LST esatto + anomalia)
  - Multi-zone LST Comparison (selezione pill, marker 2003, trend/decade in legenda)
TimelineSlider:
  - Fonte dati per anno (MODIS baseline / post-baseline / S2+MODIS)
  - Anomalia media citta (arrow + gradi vs baseline)
  - Tick colorati anni chiave (2003 heatwave rosso, 2010 grigio, 2015 arancio, 2023 verde)
