## OBIETTIVO
Applicazione per routing "fresco" a Marsiglia: percorsi pedonali/ciclabili che
minimizzano l'esposizione al calore urbano (UHI) usando dati satellitari Sentinel-2.

1. heatmap-marseille/ — DATI
================================================================================

File usati dal motore:
- marseille_uhi.tif              → raster UHI composito (Sentinel-2 Aug 2023)
- quartiers/quartiers.geojson    → confini 111 quartieri Marsiglia
- temp-analysis/MODIS_marseille_2000_2024.csv → LST storica 2000-2024
- indices/ndvi.tif               → NDVI Sentinel-2 (22 Aug 2023, tile 31TFH)
- indices/ndwi.tif               → NDWI Sentinel-2
- indices/swir.tif               → SWIR normalizzato (B11)
- indices/urban.tif              → Proxy impermeabilizzazione (B11/B08)

Copia degli indici anche in /goinfre/eielmini/heatmap-marseille/indices/ (per
compatibilita con entrambe le istanze dell'engine).

Indice UHI composito: 40% SWIR + 30% NDVI + 10% Urban + 10% NDWI
Raster CRS: EPSG:4326 — bounds: W5.25, E5.53, S43.20, N43.42 — shape 2284x2090

Indici Sentinel-2 scaricati con scripts/download_s2_indices.py da:
  AWS COG public — tile S2B_31TFH_20230822_0_L2A
  Bande: B03(Green) B04(Red) B08(NIR 10m) B11(SWIR 20m ricampionato a 10m)

Zone MODIS (9): centre_ville, nord_urbain, sud_urbain, periurbain_est,
periurbain_nord, rural_est, rural_nord, rural_ouest, rural_sud

2. marseille-engine/ — BACKEND API
================================================================================

Stack: Python 3.13, FastAPI, uv — Port: 8000
SEMPRE: UV_PYTHON=/usr/bin/python3

--- Avvio ---
make run             → solo API
make start           → API + marseille-app (5173)
make start-dashboard → API + marseille-dashboard (5174)
make start-mobile    → API + fresh-route Expo (8081)

--- Routers ---
api/routers/
├── uhi.py       → /uhi/quartiers, /uhi/quartier/{nome}, /uhi/point
├── history.py   → /history/zones, /history/{zona}
├── route.py     → /route/ (A* green routing)
├── risk.py      → /risk/?month=
├── raster.py    → /uhi/raster.png, /uhi/raster/raw, /uhi/raster/bounds,
│                   /uhi/raster/all-zones-history
├── timeline.py  → /timeline/snapshot?year=, /timeline/range
└── indices.py   → /indices/{name}/raw?scale=, /indices/available
                   name: ndvi | ndwi | swir | urban
                   Stesso wire-format di /uhi/raster/raw (float32 + X-Raster-* headers)
                   Path cercato in ordine:
                     /goinfre/eielmini/green_project/heatmap-marseille/indices/
                     /goinfre/eielmini/heatmap-marseille/indices/

--- Script utilita ---
scripts/download_s2_indices.py → scarica bande S2 da AWS COG, calcola 4 indici
  Uso: UV_PYTHON=/usr/bin/python3 uv run python scripts/download_s2_indices.py
  Gia eseguito — indici disponibili in entrambe le locazioni

--- Routing ---
A* (nx.astar_path) — green_weight: lunghezza + sconti pedonale/fresco + penalita caldo

4. marseille-dashboard/ — ADMIN DASHBOARD PROFESSIONALE
================================================================================

Stack: React 19, Vite 8, TypeScript 6, Tailwind CSS 4, Recharts, Leaflet
Port: 5174 — Proxy: /api/* → localhost:8000

Design system dark professionale:
  Token C: base #060d14, panel #0a1520, raised #0f1f30
  border #18304a, text #d4e0ec, muted #4a6a88
  hot #e05252, warm #d4914a, cool #4daa74
  No glass-morphism. Colore solo dove ha significato semantico.
  SegmentedControl per toggle. Card con top-border (2px) colorato.

--- src/ ---
api/engine.ts          → fetchQuartiers, fetchRisk, fetchHistory, fetchAllZonesHistory
types/index.ts         → tipi + ZONES + AllZonesHistory
pages/Dashboard.tsx    → pagina principale unica

components/map/
  UHIMap.tsx           → Leaflet + Canvas2D overlay + pixel probe + loading state
  WebGLRasterLayer.ts  → Canvas2D raster, cache per indice, colormaps, getValue()
  TimelineSlider.tsx   → slider 2000-2024 + fonte dati + anomalia media citta

components/charts/
  HistoryChart.tsx     → trend LST + regressione + 2003 highlight
  SeasonalChart.tsx    → profilo stagionale
  RankingChart.tsx     → 111 quartieri ordinati
  DistributionPanel.tsx → istogramma + confronto arrondissement
  AnomalyMatrix.tsx    → griglia 9zone x 25anni (blu-bianco-rosso, N/D per no-data)
  MultiZoneChart.tsx   → confronto LST fino a 4 zone, pill, recharts

--- Renderer raster ---
Canvas2D puro (no WebGL — OES_texture_float non disponibile su 42 school)
Flow: fetch float32 → normalizza in JS → putImageData → L.imageOverlay
Cache per indice: primo fetch poi switch istantaneo senza rete

--- Layer indici mappa (toolbar segmentata) ---
UHI | NDVI | NDWI | SWIR | Urban

Colormaps:
  UHI:   verde->giallo->arancio->rosso (con year-shift MODIS)
  NDVI:  rosso-bruno->giallo->verde
  NDWI:  marrone->bianco->blu
  SWIR:  verde scuro->giallo chiaro
  Urban: verde->arancio->rosso

Pixel probe interattivo (hover sulla mappa):
  - getValue(lat, lon) campiona il float32 array via nearest-neighbor
  - Pannello top-left: nome indice, valore esatto, barra colorata, lat/lon
  - UHI: mostra anno corrente quando non in hover
  - Altri indici: "Hover for value" quando idle
  - Loading spinner durante fetch di un nuovo indice

--- Features dashboard ---
Header: wordmark tipografico, Export CSV, Export GeoJSON, dot Live
KPI 5 card: avg UHI, hot/cool districts, hottest/coolest zone
Mappa: Pixel/Districts/Both + UHI Score/Heat Risk + indice selector + timeline
Districts: threshold filter slider (0-90%), lista filtrata con stats
Quartier detail: score gauge, percentile, monthly risk bars, distribution
Analysis Tools:
  - Zone x Year Anomaly Matrix (hover per LST + anomalia esatta)
  - Multi-zone LST Comparison (pill, marker 2003, trend/decade in legenda)
TimelineSlider:
  - Fonte dati per anno (MODIS baseline / post-baseline / S2+MODIS)
  - Anomalia media citta (arrow + gradi vs baseline)
  - Tick colorati anni chiave
